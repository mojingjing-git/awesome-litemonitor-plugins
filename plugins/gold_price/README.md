# 黄金价格（Gold Price）

> 伦敦现货黄金价格监控

## 功能说明

显示伦敦现货黄金（XAU）价格。

调用 `gold-api.com` 的公开接口，无需 API Key。

## 使用说明

1. 打开 LiteMonitor++ 的「设置 → 插件市场」，搜索并安装本插件
2. 在「设置 → 插件管理」中找到它，打开开关
3. 按上面的「配置项」填写参数（没有参数的可跳过）
4. 在「设置 → 监控项显示」里挑选要显示的输出项

## 注意事项

- 无需任何凭据，填好就能用。
- 接口为境外服务，**网络不通时会显示 `[ERROR]`**。
- 该接口不保证实时行情，**不应用于交易决策**，仅供参考。
- 价格按接口返回的原始数值显示，未做单位换算。
