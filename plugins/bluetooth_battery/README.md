# 蓝牙设备电量（Bluetooth Device Battery）

> 自动只显示当前连接中的蓝牙设备，按电量从低到高排列（最多 6 台），电量低于阈值红色。设备行可在 设置→监控项 中开关。需运行 BluetoothBattery.ps1 本地服务。

## 功能说明

监控当前正在连接的蓝牙设备电量。只显示**已连接**的设备，按电量从低到高排列，最多同时显示 6 台；电量低于阈值时数值变红。

数据来自本机的 `BluetoothBattery.ps1` 本地服务（默认监听 `127.0.0.1:18923`），该服务负责读取 Windows 蓝牙栈的设备电量并以 JSON 返回。

## 使用说明

1. 打开 LiteMonitor++ 的「设置 → 插件市场」，搜索并安装本插件
2. 在「设置 → 插件管理」中找到它，打开开关
3. 按上面的「配置项」填写参数（没有参数的可跳过）
4. 在「设置 → 监控项显示」里挑选要显示的输出项

## 注意事项

- **必须先运行 `BluetoothBattery.ps1` 本地服务**，否则本插件只会显示 `[ERROR]`。该脚本不在本仓库内，需要自行获取。
- 服务端口默认 `18923`，如被占用可在插件设置里改 `port` 参数。
- `warn` 参数是低电量告警阈值（百分比，默认 20），低于此值时数值变红。
- 最多显示 6 台设备（`dev1`~`dev6`）。设备多于 6 台时，**按电量从低到高取前 6 台** —— 即最需要关注的低电量设备优先显示。
- 每台设备对应一条独立的监控项，可在「设置 → 监控项显示」里单独开关；未连接的设备不占位。
- 刷新间隔 30 秒。蓝牙设备休眠后可能短暂读取失败，表现为某一行显示 `[EMPTY]`。
