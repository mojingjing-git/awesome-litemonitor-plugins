# 无线外设双电量 (鼠标/耳机)（Wireless Peripherals Battery (Mouse/Headset)）

> 实时监控英菲克无线鼠标与漫步者花再耳机电量，支持上下分行与 Emoji 图标显示

## 功能说明

实时监控英菲克无线鼠标与漫步者花再耳机的电量，分别显示上下两行，也可合并成一行带 Emoji 图标的摘要。

## 使用说明

1. 打开 LiteMonitor++ 的「设置 → 插件市场」，搜索并安装本插件
2. 在「设置 → 插件管理」中找到它，打开开关
3. 按上面的「配置项」填写参数（没有参数的可跳过）
4. 在「设置 → 监控项显示」里挑选要显示的输出项

## 注意事项

- 需要配套的本地服务在 `127.0.0.1:28888` 提供电池数据，否则显示 `[ERROR]`。
- **只支持英菲克无线鼠标与漫步者花再耳机这两款特定设备** —— 其它蓝牙设备读不到，因为服务是按这两款设备的协议写的。
- 设备休眠或断开连接时，电量可能短暂显示为空。
- 刷新间隔 5 秒。
