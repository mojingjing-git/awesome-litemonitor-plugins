# 风扇转速（Fan Speed）

> 直接读 EC，实时显示 CPU/GPU 风扇转速 — 机械革命蛟龙16 Pro

## 功能说明

直接读取 EC（嵌入式控制器）上报的风扇转速，实时显示 CPU 与 GPU 风扇的 RPM。

不走任何厂商驱动接口，因此不依赖主板厂商的监控软件。

## 使用说明

1. 打开 LiteMonitor++ 的「设置 → 插件市场」，搜索并安装本插件
2. 在「设置 → 插件管理」中找到它，打开开关
3. 按上面的「配置项」填写参数（没有参数的可跳过）
4. 在「设置 → 监控项显示」里挑选要显示的输出项

## 注意事项

- **硬编码机型**：本插件针对「机械革命蛟龙 16 Pro」编写，读取其 EC 暴露在 `http://localhost:18900/fan` 的接口。**其它机型大概率读不到数据** —— 这是从该机型适配过来的实现，不是通用方案。
- 需要对应的 EC 查询服务在 `127.0.0.1:18900` 运行，否则显示 `[ERROR]`。
- 刷新间隔 5 秒，属于比较频繁的轮询。EC 接口不稳定时可能出现数值跳变。
- EC 读取有极小概率影响系统稳定性，笔记本电池电量低时更明显。
